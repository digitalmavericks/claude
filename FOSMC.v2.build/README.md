# FOSMC.v2.build — FounderOS v2.1 Rev D packet

This directory holds the single, self-contained Rev D master plan, its checksum, the
ratification ballot, and the freeze helper.

## Files
- `FOUNDEROS_V2_1_REV_D_MASTER_PLAN.md` — the canonical plan. The five-seat vote is cast against its SHA-256.
- `FOUNDEROS_V2_1_REV_D_RATIFICATION_BALLOT.md` — signature blocks, bound to the plan hash.
- `FOUNDEROS_V2_1_REV_D_SHA256SUMS.txt` — checksums (generated by the freeze helper).
- `freeze_rev_d.sh` — computes the plan hash, binds the ballot, writes checksums.

## Sign-off workflow
1. Read `FOUNDEROS_V2_1_REV_D_MASTER_PLAN.md`. Fill any `>>> PASTE CANONICAL SOURCE TEXT HERE <<<` slots if canonical source text exists, then re-run the freeze.
2. Run `./freeze_rev_d.sh` to (re)compute and bind the hash.
3. Verify integrity: `sha256sum --check FOUNDEROS_V2_1_REV_D_SHA256SUMS.txt` (macOS: `shasum -a 256 -c`).
4. Confirm the `PLAN_SHA256` in the ballot equals `sha256sum FOUNDEROS_V2_1_REV_D_MASTER_PLAN.md`.
5. All five Council seats sign APPROVE against that exact hash.
6. DC signs the BUILD authorization. BUILD begins offline. Live promotion stays gated (section 7 of the plan).
